# ResoIA — site

Site de ResoIA : gouvernance et usage de l'IA pour les PME têtes de réseau (franchise, licence de marque, succursales).

Une page, `index.html`, et la police IBM Plex Sans hébergée dans `fonts/` (aucun appel à Google Fonts). Les vues (accueil, offres, constat, contact, mentions) s'affichent selon l'ancre de l'adresse (`#offres`, `#contact`…). Publié par GitHub Pages depuis la branche `main`.

## Formulaire de contact

Les demandes partent par Web3Forms vers contact@metivance.com. Pour l'activer, coller la clé d'accès reçue par courriel dans `CLE_WEB3FORMS`, en haut du script de `index.html`. Tant que la clé est vide, le formulaire prépare un récapitulatif à copier.

Sources : charte visuelle ResoIA, design system ResoIA, panel des acteurs et proposition de valeur (6 novembre 2026).

## Voir le site en local

Ouvrir `index.html` dans un navigateur.

## À faire avant mise en ligne

- Coller la clé Web3Forms (voir ci-dessus).
- Compléter les mentions légales (société, hébergeur, adresse de contact).
- Valider les fourchettes de prix après entretiens dirigeants.
- Vérifier le nom ResoIA à l'INPI et réserver le nom de domaine.
