# ResoIA — site

Site de ResoIA : gouvernance et usage de l'IA pour les PME têtes de réseau (franchise, licence de marque, succursales).

Une page, `index.html`, et la police IBM Plex Sans hébergée dans `fonts/` (aucun appel à Google Fonts). Les vues (accueil, offres, constat, contact, mentions) s'affichent selon l'ancre de l'adresse (`#offres`, `#contact`…). Publié par GitHub Pages depuis la branche `main`.

## Formulaire de contact

Les demandes partent par Web3Forms vers contact@metivance.com. La clé d'accès se trouve dans `CLE_WEB3FORMS`, en haut du script de `index.html`. Elle est publique par conception : elle ne permet que d'envoyer vers cette adresse. Si la clé est vidée, le formulaire prépare un récapitulatif à copier.

Sources : charte visuelle ResoIA, design system ResoIA, panel des acteurs et proposition de valeur (6 novembre 2026).

## Voir le site en local

Ouvrir `index.html` dans un navigateur.
