# ResoIA — site

Site de ResoIA : gouvernance et usage de l'IA pour les PME têtes de réseau (franchise, licence de marque, succursales).

Un seul fichier, `index.html`, sans dépendance externe : la police IBM Plex Sans et le logo y sont intégrés (aucun appel à Google Fonts). Les vues (accueil, offres, constat, contact, mentions) s'affichent selon l'ancre de l'adresse (`#offres`, `#contact`…).

Sources : charte visuelle ResoIA, design system ResoIA, panel des acteurs et proposition de valeur (6 novembre 2026).

## Voir le site en local

Ouvrir `index.html` dans un navigateur.
